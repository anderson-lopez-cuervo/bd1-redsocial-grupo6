## Breve descripción del caso

Este proyecto propone el diseño de una plataforma educativa y social universitaria orientada a facilitar la interacción, colaboración y conexión entre estudiantes.

La plataforma permitirá a los usuarios crear perfiles académicos y personales, registrar sus áreas de estudio, intereses, habilidades, deportes o actividades extracurriculares, y encontrar otros estudiantes con afinidades similares.

También permitirá seguir a otros estudiantes, establecer relaciones de mentoría, publicar contenido como preguntas académicas, recursos, noticias o contenido relacionado con la vida universitaria, así como comentar y reaccionar a publicaciones.

Adicionalmente, los estudiantes podrán crear y unirse a grupos de estudio, equipos para hackatones, clubes y comunidades de interés. La plataforma también permitirá programar eventos como reuniones de estudio, talleres, hackatones y actividades sociales, gestionando la participación de los usuarios.

Como parte del proyecto se diseñó un **modelo entidad-relación (ERD)** normalizado hasta **Tercera Forma Normal (3FN)**, con el objetivo de establecer una base de datos relacional organizada, escalable y preparada para una futura implementación en PostgreSQL.
